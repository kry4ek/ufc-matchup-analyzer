# Dataset provenance and publication gate

The snapshot originates from UFCStats (http://ufcstats.com), with repaired statistics and derived model features produced by the retained project code. It reaches 2026-09-26. `dataset_manifest.json` inventories the exact files, hashes, schemas, row counts, and dates. CSV datasets and the bundled runtime are distributed in separate release archives, outside source Git history.

The MIT license applies to project code; it does not grant a license to UFCStats source material or UFC trademarks. The project owner confirmed that no redistribution permission is held, and no explicit open-data redistribution license has been established for this snapshot. This candidate's dataset redistribution status is **review_required**.

On **October 1, 2026**, the project owner explicitly requested publication of the full portable app and accepted the possibility of a GitHub takedown. This is an owner publication decision, **not evidence of redistribution permission or a legal determination**. The dataset status remains `review_required`; the data must not be relabelled as MIT licensed. A complaint-response policy does not establish redistribution rights.

The standard fully verified release gate still requires documented rights and every required check. Its failure remains visible in `release_checks.json`. This publication is an experimental prerelease with unresolved rights and verification limitations, recorded separately from test outcomes. If a documented redistribution basis is later established, record the evidence here before changing `redistribution_status` to `cleared`.

Source links are retained in raw records where available. This project is independent and is not endorsed by UFC or UFCStats.
