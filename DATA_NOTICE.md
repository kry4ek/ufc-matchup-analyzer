The source-only repository contains this inventory, not the CSV snapshot, runtime or bundled app.

The MIT license applies to project code; it does not grant a license to UFCStats source material or UFC trademarks. The project owner confirmed that no redistribution permission is held, and no explicit open-data redistribution license has been established for this snapshot. This candidate's dataset redistribution status is **review_required**.

The local ZIPs are prepared for the project owner's review. **Do not publish the dataset archives or portable Windows ZIP until redistribution permission or another documented basis has been established.** Record that evidence in this notice and set `redistribution_status` to `cleared` in the dataset manifest before invoking the publication gate. The source-only development preview excludes those files and has no public dataset download or supported from-scratch data-acquisition workflow. It must not be presented as a ready-to-run portable release; do not relabel the data as MIT licensed.
