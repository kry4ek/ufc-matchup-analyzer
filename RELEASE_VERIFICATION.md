# v0.8 experimental prerelease verification

Current checks are recorded in [v0.8 verification](docs/V0_8_VERIFICATION.md), [performance measurements](docs/V0_8_BENCHMARK.md) and `verification_evidence.json`.

All five app changes are implemented and locally verified. Clean Windows 10/11 and actual alternative display-scaling checks are deferred. Dataset redistribution remains `review_required` and the launcher is unsigned; this is not a stable release.

The owner authorized GitHub publication on 16 October 2026. The [v0.8 release](https://github.com/kry4ek/ufc-matchup-analyzer/releases/tag/v0.8.0) supplies archive checksums, local verification, exact-commit CI and post-publication anonymous-download proof as separate assets. Embedded local evidence is a snapshot from before publication, not a claim that later checks were already complete. These publication checks do not clear the outstanding rights, clean-OS, physical-DPI or signing gates.

Historical [v0.7 verification](docs/RELEASE_VERIFICATION_V07.md) is preserved separately.
