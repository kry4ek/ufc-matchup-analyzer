The application presents this as `LIMITED_RETROSPECTIVE_EVALUATION`.

The embedded release gate points to that external record instead of trying to include the archive's own final checksum.

The unchanged snapshot can contain later source corrections. Historical evaluation is not prospective performance. The fold issue requires a separate parent research correction and new evaluation. A limited retrospective report does not clear a clean model-validation gate.
