# v0.5 local release candidate verification

All four implementation milestones and local workflow checks passed on 12 October 2026. This is a local portable candidate; the public download remains v0.4.0. Source CI and public-download verification for v0.5 have not run.

The candidate retains all 15 original datasets (206,791,890 bytes, through 26 September 2026), men's v3 algorithm and women's existing ensemble. Neither the research parent nor the separately installed portable app was changed. Historical reports use the installed facts, which can include later source corrections.

Cold-run timing was investigated separately. The first fresh native men run took 160.85 seconds versus the earlier 134.76-second baseline (19.4% slower). Recorded population-history traversal grew from 122.555 to 133.860 seconds, with additional resource/cache preparation and persistence. Earlier repeated cold runs overlapped full correction rebuilds. Women fresh native cold took 184.59 seconds versus 216.6 seconds. Host variation is material; no first-run speedup is claimed. The measured improvement applies to compatible subsequent matchups.

The runtime and native launcher are reused only after verifying every declared runtime/launcher hash, matching pinned runtime-input/dependency manifests and confirming unchanged launcher source. A clean deliverable is rebuilt after workflow QA. Archive inventories, member hashes and CRCs, fresh ZIP extraction and actual native EXE startup are delivery checks; their evidence is retained beside the local ZIP in `archive_manifest.json`, `SHA256SUMS.txt` and `ZIP_VERIFICATION.json`. Computational artifacts, personal history, transaction data, captured pages and work files are excluded.

Machine-readable local results are in `verification_evidence.json`; prior v0.4 results remain in `docs/verification_evidence_v04.json` and `docs/release_checks_v04.json`. Raw logs, forecasts and owned-window screenshots are retained locally under `work/v05-*` and are not release contents.

Separate clean Windows 10/11 installations and physical 100/150/200% OS scaling remain unverified. Dataset redistribution review remains unresolved. These existing limitations are preserved; none is counted as a passed v0.5 publication gate.
