# Upgrade to the local v0.8 candidate

Extract the complete new portable ZIP into a new writable folder and launch its EXE. Keep the old folder while checking your saved analyses and a new comparison.

Use Data & maintenance → Import from previous installation to review and import eligible history/preferences. Existing import capacity, duplicate/conflict handling, rollback and undo remain available. Datasets and calculation caches are not imported.

Older reports keep their original values, evidence and generation time. If bout details or recent form were not recorded, those views explain that limitation. Select Refresh and compare to capture a new result using installed data. The default retains the original matchup date; choosing today's date changes eligibility and is shown in the comparison. Manual CLI profile reports require the original profile file.

Recent fights now has Show bout details. Select a bout and use its button, Enter or double-click. Statistics contains an expandable Recent form versus UFC career section with Last 3/Last 5 choices; Overview links to it. Select a metric to read the exact recorded support.

Save report includes Compact summary — Last 3 and Last 5. Open the HTML offline, then use the browser's Print/Save as PDF. Print at 100%, choose A4 or Letter and turn off browser headers/footers. Keep the detailed report when you need every metric and full methodology.

The data snapshot and model policy are unchanged by this application upgrade. Computation/result compatibility includes the new code, so a first request may prepare new work. Subsequent content-compatible work can be reused. Full Recalculate still bypasses computation caches; Refresh captures a new report while allowing them.

This is a local experimental candidate. Clean Windows 10/11 and actual alternative display-scaling tests are deferred. Current-machine portable/GUI checks and simulated scaling are documented separately. Dataset redistribution remains `review_required`; signing and stable-release limitations remain. Publication and prospective tracking are outside this iteration.
